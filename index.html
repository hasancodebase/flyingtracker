Included Cloudflare Functions (in this package)

functions/api/live.js — ADSB.lol proxy + cache
export async function onRequest(context){ const { request, env } = context const url = new URL(request.url) const lat = url.searchParams.get('lat') || '50' const lon = url.searchParams.get('lon') || '-25' const dist = url.searchParams.get('dist') || '500' const upstream = `https://api.adsb.lol/v2/lat/${lat}/lon/${lon}/dist/${dist}` const res = await fetch(upstream, { cf: { cacheTtl: 10 } }) return new Response(res.body, { headers: { 'Content-Type': 'application/json', 'Cache-Control': 'public, s-maxage=10, stale-while-revalidate=20', 'Access-Control-Allow-Origin': '*' } }) }

Deploy to Cloudflare (2 min)

  1. Upload to Cloudflare: Go to dash.cloudflare.com → Pages → Create project → Upload assets. Drag the whole cloudflare-flight-tracker folder (this file + /functions).
  2. Framework preset: None. Build command empty, output directory / or .
  3. Add domain: Pages → Custom domains → yourdomain.com (free SSL).
  4. Commercial tip: In Pages → Settings → Functions, add KV namespace TRACKS if you want to cache NAT tracks beyond 5 min. No env vars needed for basic version.
  5. Test live: After deploy, open yourdomain.com/api/live?lat=50&lon=-25&dist=500 and /api/tracks. Should return JSON with CF cache headers.
  6. Own receiver (optional but gives you unlimited): On your Pi: readsb --json --net → POST every 5s to a secret Worker /api/ingest you add. Then your /api/live merges local + ADSB.lol.

Why Cloudflare over Vercel for commercial
Vercel free = 100GB bandwidth, function timeouts, non-commercial edge cache nuances. Cloudflare Pages free = unlimited bandwidth, 0$ R2 for tiles, Workers KV for NAT cache, and you can keep ADSB keys server-side.
NAT Tracks daily
Tracks published twice daily: eastbound ~1400Z, westbound ~2200Z. Valid window over 30°W. This build caches them for 5 min on edge. Add a Cron Worker to fetch twice daily for production.
What to show on map
MapLibre + GeoJSON: Polyline for track route, Circle for waypoints, tooltip with ID, TMI, FLs, validity. Aircraft layer from /api/live. Auto-refresh 10s.
